Measure the field. Keep the pump manual.

Camera documents the soil surface. Probe measures root-zone moisture. Other sensors record local air, water flow, and pump status. Readings help people review the plan; device sends no control commands.

Signal path

Separate observation from interpretation.

Surface image

Camera points at a fixed soil patch. Photo records visible color, cracks, cover, or ponding; it does not measure subsurface moisture or soil chemistry.

Ground sensors

One root-zone moisture probe, air temperature/humidity sensor, and inline flow meter feed timestamped numeric readings.

Pump status

Read-only, isolated status input from a compatible pump controller. Missing contact means “unknown”; do not infer status from a command.

CaptureCamera image + sensor sample, each with its own timestamp.
ValidateFlag missing, stale, or implausible readings; retain source and quality state.
CompareApp shows measured values beside regional satellite/weather context.
ReviewEngine recalculates options; farmer reviews and chooses any plan change.
Data delivery options

Realtime when connected. Batch when not.

One code path writes a timestamped JSON observation. Transport mode changes sampling and upload timing, not sensor meaning.

Realtime pilot mode

  • Sensor sample each 60 seconds.
  • Surface photo each 5 minutes.
  • Transfer through local Wi-Fi when connected.
  • App tags mode, source, capture time, and quality.

Batch pilot mode

  • Sensor sample each 30 minutes.
  • Two surface photos each day.
  • Queue records locally; upload after connection returns.
  • App shows capture time separately from upload time.
Prototype status: app currently replays synthetic telemetry to demonstrate both modes. No physical device, image upload, or realtime endpoint is connected.
